# 本地电影与美剧收藏网站设计

## 目标

创建一个无登录的私人本地媒体库网站。它展示收藏的电影与美剧，并能在浏览器内播放由用户授权、存放在本机资源目录中的视频。

## 范围

- 首页展示收藏内容，包含“全部”“电影”“美剧”三个分类。
- 搜索范围受当前分类限制：在“电影”中仅搜索电影名称；在“美剧”中仅搜索剧名；在“全部”中搜索电影名和剧名。
- 电影卡片进入播放器后直接播放单一视频。
- 美剧卡片只使用一张剧集海报；进入详情页后按季、集选择本地视频播放。
- 无用户账户、登录、收藏操作、观看进度、下载、在线资料 API 或云端服务。

## 技术边界

首版为纯前端静态网站。浏览器从站点同源路径获取配置、片单、海报和视频；网站必须经静态文件服务器运行，不能通过直接双击 HTML 文件打开。

浏览器无法安全地按绝对路径扫描任意电脑目录。因此配置文件只能指定由静态服务器公开的、相对于网站根目录的媒体路径。自动扫描任意本地目录属于未来的本地后端能力，不在本期实现。

## 文件与数据约定

```text
config.json
data/movies.json
movie_resources/
  movies/
    silence-of-the-lambs.mp4
  series/
    breaking-bad/
      s01e01.mp4
      s01e02.mp4
  posters/
    silence-of-the-lambs.jpg
    breaking-bad.jpg
```

`config.json`：

```json
{
  "mediaDirectory": "./movie_resources"
}
```

`data/movies.json` 保存一个统一条目数组。所有资源字段为相对于 `mediaDirectory` 的路径。

电影条目：

```json
{
  "id": "silence-of-the-lambs",
  "type": "movie",
  "title": "沉默的羔羊",
  "year": 1991,
  "genres": ["剧情", "惊悚"],
  "description": "影片简介由片单维护。",
  "poster": "posters/silence-of-the-lambs.jpg",
  "video": "movies/silence-of-the-lambs.mp4"
}
```

美剧条目：

```json
{
  "id": "breaking-bad",
  "type": "series",
  "title": "绝命毒师",
  "year": 2008,
  "genres": ["剧情", "犯罪"],
  "description": "剧集简介由片单维护。",
  "poster": "posters/breaking-bad.jpg",
  "episodes": [
    { "season": 1, "episode": 1, "title": "化学课", "video": "series/breaking-bad/s01e01.mp4" }
  ]
}
```

## 页面与交互

顶栏含品牌、分类控制和搜索框。分类切换后立刻更新网格与搜索范围提示；保留已有查询并按新范围重新过滤。搜索使用大小写不敏感的名称包含匹配，不检索年份、类型、简介或剧集标题。

收藏网格以海报、名称和内容类型为主。缺少海报时显示有名称的文字占位封面。点击电影打开播放器页；点击美剧打开详情页，展示该剧唯一海报、简介、季选择与对应的集按钮。点击集按钮在播放器页播放该集。

播放器使用原生 HTML `video` 控件，提供播放、暂停、时间轴、音量和全屏。播放器无法加载或播放视频时显示清晰错误信息并提供返回收藏页的操作。

## 错误处理

- 配置或片单加载失败：显示无法读取媒体库的提示，不渲染误导性空内容。
- 条目缺少海报：使用占位封面。
- 条目缺少视频或视频加载失败：保留条目和元信息，在打开时说明文件不可用。
- 美剧没有剧集：详情页显示“暂未添加剧集”。
- 无搜索结果：显示当前分类下无匹配内容的空状态。

## 验收与验证

- 示例电影与美剧都能从片单正确渲染，路径由 `config.json` 和 `movies.json` 组合得到。
- 三个分类显示正确内容；查询不会越过当前分类，并且不会因剧集标题而命中。
- 电影可进入相应播放器；美剧可进入详情并选择集播放。
- 海报、视频、配置和片单异常分别呈现约定的兜底状态。
- 桌面和手机宽度下，导航、搜索、网格、详情与播放器都可用。
